# Monolith Tower Defense Suite

**Founder & Lead Architect**: Mike  
**Studio**: Monolith Games Inc.  

## 🏰 Overview
Grid-based and waypoint pathfinding tower defense games built using Cocos Creator, Unity, and Jetpack Compose.

## 📂 Featured Titles & Frameworks
- **`defensegridtactics`**: Wave-based tactical turret defense game.
- **`Roadblock`**: Cocos Creator tower defense project consuming `cocos/frameworks/tower-defense-framework/`.
