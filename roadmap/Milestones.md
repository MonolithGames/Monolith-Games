# Monolith-Games Enterprise Roadmap

- **Milestone 1**: Multi-module Android architecture migration (`launcher`, `gamehub`, core libraries, and game modules).
- **Milestone 2**: Integration of C, C++, and C# high-performance engines (`/engines`).
- **Milestone 3**: Enterprise backend microservices deployment (`auth-service`, `game-service`, `leaderboard`, `telemetry`).
- **Milestone 4**: Automated GitHub Actions CI/CD pipelines for cross-platform builds and publishing.
