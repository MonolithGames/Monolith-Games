# Monolith Procedural Water Simulations Suite

**Founder & Architect**: Mike // Monolith Games Inc.  
**Catalog Size**: 75+ High-Performance HTML5 Canvas & WebGL Fluid Engines  

## 🌊 Suite Overview
This package contains 75+ self-contained, high-framerate procedural water, fluid, and wave simulations engineered using raw HTML5, WebGL, GLSL Shaders, and Canvas 2D matrix projection mathematics.

### Key Asset Categories
1. **3D Heightfield & Wireframe Meshes**: Isometric raymarched pools, synthwave grid-waves, and axonometric topography.
2. **2D Flowfields & Vector Currents**: Hydrodynamic velocity particles, dual-nexus vortical drains, and foam trails.
3. **Subsurface Caustics & SVG Displacements**: Shimmering pool light caustics and photo distortion filters.
4. **Retro Pixel & Cellular Automata**: 8-bit falling pixel water channels, sand/fluid falling block physics.
5. **ASCII Matrix Typographic Ocean**: Multi-layer parametric text ocean waves and digital rain cascades.

## 🛠️ Integration Instructions

To embed any simulation into your website, desktop client, or stream overlay:

```html
<iframe src="path/to/simulation/index.html" 
        style="width: 100%; height: 100vh; border: none;" 
        allow="autoplay">
</iframe>
```
