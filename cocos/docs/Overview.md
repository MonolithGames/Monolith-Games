# Cocos Creator Multi-Project Engine Suite

Official Cocos Creator project suite for cross-platform 2D & 3D mobile games.

## Directory Structure
- **`projects/`**: Active game titles (`roadblock`, `tank-line`, `block-breaker`, `space-shooter`).
- **`templates/`**: Production starters (`tower-defense`, `match3`, `idle`).
- **`shared/`**: Common assets and modules (`ui`, `audio`, `ads`, `saves`).
- **`docs/`**: Architecture & design guides.
