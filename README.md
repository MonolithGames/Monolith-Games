# Monolith Games

Welcome to the official repository for Monolith Games. This repository is structured for maximum clarity, allowing developers and contributors to immediately navigate our apps, games, assets, and backend services.

## Repository Directory Map

| Directory | Description |
| :--- | :--- |
| **`android/`** | Android applications and mobile launchers |
| **`games/`** | Game titles (`alphabet-media/`, `prototypes/`, `shared/`) |
| **`assets/`** | Global textures, audio, models, and UI art assets |
| **`backend/`** | Cloud services, authentication, and telemetry backends |
| **`docs/`** | Architecture designs, specifications, and reports |
| **`roadmap/`** | Project milestones and release planning |
| **`scripts/`** | Build, automation, and deployment scripts |
| **`tools/`** | Internal asset pipelines and developer tools |
| **`config/`** | Global configuration profiles and environment templates |
| **`third-party/`**| External dependencies and submodule integrations |
| **`.github/`** | CI/CD GitHub Action workflows and templates |
